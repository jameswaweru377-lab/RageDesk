# RageDesk 0.8 — Deep Navy UI (Preview 3)

This Windows preview includes the approved **deep-navy RageDesk dashboard** and fixes the downloads list layout: the selection toolbar now stays **above** the downloads table rather than leaving a large empty area beside it.

## Install without PowerShell

**Download:** `RangeDesk-Setup-0.8.0-preview.3-win-x64.exe` from the release assets below. Double-click the installer, choose English or Kiswahili, and complete setup.

From the Start Menu choose **RageDesk - New UI Preview** to open the deep-navy React/WebView2 dashboard. The installer also keeps the regular **RangeDesk** shortcut, which opens the existing full-function WPF interface.

If you select **Launch RageDesk** at the end of installation, it opens the original WPF app; choose the **New UI Preview** Start Menu shortcut to view the new design. No terminal commands are required.

**Important:** The new UI is still a **preview**, not a full replacement for the WPF app. The React dashboard uses live data from the existing C#/.NET 10 engine; sorting, searching and navigation work in React. Add Link and New Download open the existing native WPF dialogs; delete, file management, scheduler and some Settings actions are still WPF-only. A second WPF window stays open while you use the React preview because it owns the download engine. The independent download-progress popup remains WPF-based.

## What's new in this version

- Ultra-deep navy/near-black surfaces, carefully constrained electric-blue accents, richer contrast, stronger card depth and subtle illuminated borders.
- Windows dark title bar follows the selected dark theme; Arctic light mode retains a light frame.
- Fixed downloads-table arrangement: selection controls now stack above the table, and horizontal scrolling remains inside the table without pushing download rows to the side.
- Improved coloured categories, badges, file icons, segmented download progress, compact extension invitation and the dashboard's bottom information strip.
- A horizontal-tab Settings **preview** backed by safe, read-only native preferences. Write changes through the existing WPF Settings.
- Dedicated installed **New UI Preview** shortcut and a portable-preview launcher.

## Upgrades, privacy and verification

The installer upgrades previous 0.8 previews using the same AppId; download history, partial transfers and user preferences are retained in the existing local data directory. No new remote sync or telemetry is enabled, and the React interface is served from local bundled files.

This is an **unsigned prerelease**. Windows SmartScreen may show an Unknown Publisher warning. Obtain the EXE only from the official RageDesk GitHub release, and follow security restrictions on managed PCs.

The automated pipeline checks the React/TypeScript build, existing .NET tests, browser/native-host integration, self-contained Windows packaging, installed Start Menu entries, English/Kiswahili installer flows, upgrade, uninstall, and data preservation. It does **not** prove full React-native feature parity or pixel-perfect screenshots at every DPI.

If the React preview fails because WebView2 is unavailable, use the normal RageDesk shortcut. Shared Evergreen WebView2 Runtime may be needed for the preview.

**Portable alternative:** `RangeDesk-Portable-0.8.0-preview.3-win-x64.zip` includes `RangeDesk.exe` plus `Preview-New-RageDesk.cmd` to open the new UI with a double-click.

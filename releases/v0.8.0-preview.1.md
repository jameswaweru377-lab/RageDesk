# ✨ RangeDesk 0.8 — Arctic Glass

**Your downloads, beautifully organized. A proper Windows installer at last.**

Welcome to the first installable **RangeDesk 0.8 Preview 1**! This independent, local-first Windows download manager now offers an easier setup and the Arctic Glass design.

## ⬇️ Download and install

**Most people should choose:** **RangeDesk-Setup-0.8.0-preview.1-win-x64.exe**

Double-click the EXE:

1. 🌍 Choose **English** or **Kiswahili**. Main Kiswahili wizard pages and the agreement are translated; uncommon system/error messages may remain in English.
2. 📜 Read and **accept the preview software agreement**.
3. 👤 Choose **Just for me** (default; no administrator password) or **All users** (administrator approval).
4. 📁 Choose the install folder. The default is **AppData / Local / Programs / RangeDesk** for one user, or **Program Files / RangeDesk** for everyone.
5. 🖥️ Optionally create a **desktop shortcut**. A Start Menu shortcut and Windows uninstall entry are created automatically.
6. ✅ Select **Install**, then optionally **Launch RangeDesk** on completion.

To remove the application later, use **Windows Settings → Apps → Installed apps** or **Control Panel → Programs and Features**.

**No installation preferred?** Choose **RangeDesk-Portable-0.8.0-preview.1-win-x64.zip**, extract the whole folder and open RangeDesk.exe.

## 🎨 What's new

- **Arctic Glass:** a modern light-blue/white downloads screen with more readable status rows, redesigned dialogs and clearer Settings.
- **Colorful sidebar icons:** categories and site groups are kept, while the redundant Labels section is hidden.
- **Unified download workflow styling:** matching browser confirmation and desktop download actions; accepted browser jobs appear in the normal RangeDesk download list.
- **V7.1 adaptive connections (optional):** measured 2→4→8→16/32 connections, stabilized measurement windows on large transfers, re-tests after temporary plateaus, and safe retirement between range pieces.
- **Reliable resume:** validator-aware partial checkpoints, temporary HTTP failure recovery and SHA-256 verification support.
- **Queue and browser support:** current queued/scheduled jobs and opt-in browser integration remain.

## 🔐 Files, upgrades and privacy

- Download catalog, preferences and resumable checkpoints stay **local** to your Windows account.
- Upgrading does not deliberately remove saved downloads or incomplete parts.
- Uninstall removes application files but **preserves** downloaded files and local history/checkpoints.
- Chrome integration is not enabled silently; set up the unpacked extension explicitly in RangeDesk Settings.
- Video functionality can require separately supplied yt-dlp and ffmpeg, and does not work with all sites or protected media.

## ✅ Tested

Windows CI compiles and tests the app, browser and native host. The installer is additionally tested for **installation, an English/Kiswahili upgrade, Start Menu shortcut, Windows Installed Apps registration, uninstall and saved-state preservation**.

Use the included **SHA256SUMS.txt** to verify release downloads.

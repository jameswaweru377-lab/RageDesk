# 🔷 RangeDesk 0.8 Preview 2 — Cobalt Flow

**The dark-blue design you selected, plus a real Dark / Light switch.**

This release corrects the appearance of Preview 1. The default desktop experience now follows the **Cobalt Flow** concept, with navy surfaces, bright blue actions, vivid category icons, a more focused download table, and cleaner download details.

## ⬇️ Install

**Most users:** download **RangeDesk-Setup-0.8.0-preview.2-win-x64.exe** below.

The installer offers English or Kiswahili, a preview license agreement, per-user or all-users installation, an editable folder, shortcuts and an optional launch after setup. It registers with Windows **Installed apps / Programs and Features** and includes its uninstaller.

Already using Preview 1? Close RangeDesk first. This new installer uses the same AppId and upgrades your installation without deliberately deleting saved download records or incomplete transfer checkpoints.

**Portable:** choose **RangeDesk-Portable-0.8.0-preview.2-win-x64.zip** instead.

## ✨ What's new

- **Cobalt Dark is the default.** Navigation, download rows, status filters, details and Settings now use coordinated navy surfaces and high-contrast text instead of the unexpectedly all-white theme.
- **Appearance switch:** Settings → General → Appearance → choose **Cobalt Dark** or **Arctic Light**, then Save. Your choice is saved on this PC for future launches.
- **Focused Settings:** left-hand section navigation gives more room to controls and better matches the approved design reference.
- **More sensible download details:** completed files show **Open File**, **Folder**, and **Download Again**. They do **not** display nonsensical Pause or Resume buttons. Paused/failed/canceled tasks offer Resume; queued tasks offer Start; active normal transfers offer Pause.
- **Download Again without overwriting:** creates a new task and a uniquely named destination, preserving the existing completed file.
- **Cobalt browser confirmation:** the Chrome-native quality-selection and download-start overlay also uses the dark-blue design, while preserving its secure, user-approved handoff and minimized progress panel.
- **V7.1 download optimizer, safe checkpoints and recovery** remain intact.

## 🧪 Verification and safety

Windows .NET, browser and native-host checks run in GitHub Actions. The bilingual installer is built and tested for installation, Start Menu, uninstall registration, upgrade, uninstall and saved-user-data preservation. See the supplied **SHA256SUMS.txt** for download checksums.

**This is an unsigned preview.** Windows may show an Unknown Publisher / SmartScreen warning. Obtain this EXE only from the official RageDesk Releases page and follow the security policy on any managed PC. Source is independent of IDM.

**Known limitation:** automated tests do not verify a pixel-perfect Windows rendering at every screen size. Browser overlay theme is set to Cobalt; changing the desktop theme does not yet synchronize Chrome's own popup theme. Existing saved download tasks keep their original URLs, destinations and resume state.

Report reproducible issues at [RageDesk Issues](https://github.com/jameswaweru377-lab/RageDesk/issues).
